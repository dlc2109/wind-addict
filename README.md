# wind-addict
Wind Addict
Descripción:
Wind Addict es un caso de estudio diseñado para explorar y demostrar habilidades en el desarrollo web. Este proyecto combina HTML y SCSS para crear una experiencia visual y estructurada que resalta las mejores prácticas en diseño y desarrollo front-end.

Composición del proyecto:

HTML (43.6%): Estructura semántica y accesible para el contenido del proyecto.
SCSS (56.4%): Estilización modular y escalable basada en el preprocesador CSS.
Objetivos del proyecto:

Demostrar técnicas modernas de diseño web.
Utilizar SCSS para mejorar la organización y reusabilidad de estilos.
Crear una estructura HTML clara y optimizada.
